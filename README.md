# 🌐 Personal Portfolio

Welcome to my **Personal Portfolio Website**! 🚀

This portfolio is designed to showcase my **skills, projects, education, experience, certifications, and achievements** as a Bachelor of Information Communication Technology (BICT) student and aspiring IT professional.

The website focuses on a **modern, responsive, and interactive user experience**, allowing visitors to easily explore my technical journey and projects.

## ✨ Features

* 🏠 **Home** – Introduction and personal branding
* 👩‍💻 **About Me** – Background, interests, and professional journey
* 🛠️ **Skills** – Technical skills, programming languages, and tools
* 💻 **Projects** – Academic, personal, web development, and UI/UX projects
* 🎓 **Education** – Academic qualifications
* 💼 **Experience** – Internship and professional experience
* 🏆 **Certificates & Achievements** – Certifications, awards, and accomplishments
* 📩 **Contact** – Contact information and social links
* 📱 **Responsive Design** – Optimized for desktop, tablet, and mobile devices
* ✨ **Interactive Animations** – Smooth animations and modern UI interactions

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling, layouts, animations, and responsive design
* **JavaScript** – Interactive functionality
* **Figma** – UI/UX design and prototyping
* **Git & GitHub** – Version control and project management
